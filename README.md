# Análise de Textos - SRI

Projeto desenvolvido para a disciplina Tópicos Especiais I

## Descrição
Foi utilizado um dataset de tweets em português relacionado a crimes. O conjunto foi processado com técnicas de NLP utilizando a biblioteca spaCy.

## Etapas realizadas
- Limpeza e segmentação dos textos
- POS Tagging (classificação gramatical)
- NER (reconhecimento de entidades nomeadas)
- Análise de dados com gráficos e tabelas

## Tecnologias
- Python
- Pandas
- spaCy
- Google Colab

## Estrutura
- data/: arquivos CSV gerados
- notebooks: processamento e análise
